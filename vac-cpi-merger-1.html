VAC/CPI History Merger v1.0

Consolidates VAC and CPI history from up to three source types into one file ready to upload as the Gate Tracker's VAC Tracker Log. Dedup priority: VAC Tracker Log > Bench Cost CSV > EVM Manager Reports — first source wins on a same-day same-WO collision. Output schema: Date, WO, Part #, VAC, CPI. All processing is client-side — no data leaves the browser.

1. VAC Tracker Log (optional)

Previously exported vac-tracker-log-*.csv from the Gate Tracker. Accepts 3-col, 5-col, or 14-col variants.

2. Bench Cost Performance CSV (optional)

Comma-delimited file with columns Date, Order, Part #, Earned Hours, Actual Hours, CPI, VAC (plus any others — extras ignored).

3. EVM Manager Reports (optional, multiple)

One or more saved evm-report-*.html files. Extracts each report's "P File Data As Of" date plus all Bench Cost Performance Summary rows.
