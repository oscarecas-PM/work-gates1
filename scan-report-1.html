Scan Report v1.0

Upload barcode scan data or mobile audit CSVs to analyze scanning compliance and work order location metrics. Optionally upload a Master Gates CSV (with Scanned Location column) to map scan locations to gate names.

1a. Scan Data CSV

Required columns: Work Order Id, Date Time, Location

1b. Mobile Audit CSVs (alternative)

Columns: Gate Number, Order No., Part No., Serial No. Filename must contain date (mobile-audit-YYYY-MM-DD.csv). Select multiple files.

2. Master Gates CSV (optional)

Must include "Scanned Location" column to map scan locations to Gate Names.
